# Roster scope and historical notes

Scenario frame: approximately 1490 CE, not a strict single-year diplomatic snapshot. Polities are included as playable abstractions across East Asia, South Asia, Southeast Asia, West Asia, Europe, Africa, and the Americas. Several labels cover dynastic states across their wider historical identity; some leader names represent a ruler associated with the period, not necessarily a precise 1490 enthronement.

## Specific caution
The Malay world is represented through Melaka, Majapahit, Demak, Aceh, Brunei, Sulu, Ayutthaya, Lan Xang, and Ava. This is not intended to claim that every listed polity shared the same borders or diplomatic status in 1490. Before a public historical release, perform a dedicated date-by-date source audit and correct leaders/city lists where required.
