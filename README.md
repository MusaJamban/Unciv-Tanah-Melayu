# Tanah Melayu — World c.1490 (Unciv ruleset)

An original, standalone Unciv ruleset themed around the world’s major regions and polities around 1490 CE, from Asia and Europe to Africa and the Americas. It includes an expanded 18-column technology tree from early agriculture through industrial-era infrastructure, alongside culture, policy branches, faith, religions, regional improvements, 50 buildings and 50 units, a global roster of 70+ civilizations and city-state entries, original nation emblems and expanded faith/culture gameplay, unique units, and a deliberately overpowered Kesultanan Melaka.

## Design commitments
- One integrated base ruleset: no other mod is required.
- Melaka is intentionally MAX-strong, but still researches technologies and constructs buildings through the normal tree.
- Historical roster is a playable interpretation of the late-15th-century world; boundaries and dates are simplified for gameplay.
- Artwork in `Images/NationIcons` is generated for this project and does not reproduce historical flags or other mod assets.

## Install
1. Download this repository as ZIP or use Unciv → Mods → Download mod from URL.
2. Select `Tanah Melayu - Ruleset` as the base ruleset for a new game.
3. Start with Ancient era to use the full technology/building progression.

## Important status
This package is structurally complete as a first playable ruleset build, but it must still be loaded in the current Unciv client and checked with its in-game Ruleset validation. JSON syntax and cross-file references are checked by the included script; that is not a substitute for runtime testing.
