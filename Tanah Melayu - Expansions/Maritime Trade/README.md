# Tanah Melayu — Maritime Trade

Trade routes, ports, and Indian Ocean commerce.

## Planned/implemented scope
- Melaka Straits trade focus
- Port-city flavor and maritime unique content
- Expansion scope remains compatible with the core research progression

This directory is an expansion content specification, not a separately loadable Unciv mod yet. The current tested package includes the core integrated roster; expansion manifests must be converted into game JSON and runtime-tested before being marked installable.
