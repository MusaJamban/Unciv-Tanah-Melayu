# Leader portrait icons

The 32 portrait icon files in this directory are now present and use the exact `leaderName` filenames from `jsons/Nations.json`.

## Important visual note

These are original, stylized 32×32 pixel-art bust icons designed as a consistent visual set. They are **not historically accurate likenesses or researched portraits** of the named rulers. Treat them as a first complete visual pass; replace them with historically researched artwork later if you want realistic leader portraits.
