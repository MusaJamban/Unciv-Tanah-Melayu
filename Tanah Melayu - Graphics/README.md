# Tanah Melayu — Graphics

Original abstract nation emblems and icon resources for this project. They are not reproductions of historical flags, and are not copied from other Unciv mods.

The game-facing copies are retained inside `Tanah Melayu - Ruleset/Images/`; this folder is the organized asset collection for repository review. The current artwork focuses on nation icons; dedicated unit/building/technology atlases can be expanded after in-client asset validation.
